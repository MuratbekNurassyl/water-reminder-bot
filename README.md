# Water Reminder Bot
A Telegram bot built with Python that helps users track their water intake and receive reminders.

## Functions

- `/start` — show available commands
- `/drank 300` — add consumed water
- `/status` — check daily water progress
- `/setreminder 60` — set a reminder interval
- Automatic water reminders
- Daily water goal of 2000 ml

## Technologies

- Python
- Telegram Bot API
- pyTelegramBotAPI
- Schedule
- Threading
- python-dotenv

## About the Project

This project was created to practice Python, Telegram bot development, scheduling, working with APIs, and handling user data.

## Security

The Telegram bot token is stored in an environment variable and is not included in the repository
